# 🚀 FunPaySemlex

> **FunPaySemlex** — это высокопроизводительный, легкий и эффективный аналог [FunPayCardinal](https://github.com/sidor0912/FunPayCardinal/), переписанный на C++.

Проект создается с целью предоставить мощный инструмент для автоматизации работы с FunPay с минимальным потреблением ресурсов и возможностью расширения через плагины на Python и C++.

---

## ⚠️ Статус проекта

Проект находится на **ранней стадии разработки (Early WIP)**. Архитектура ядра и базовые модули в процессе активного написания.

---

## 🔥 Ключевые особенности и преимущества

* ⚡ **Высокая производительность и низкое потребление RAM:** Написан на C++, что обеспечивает мгновенный отклик и потребление памяти в десятки раз меньше, чем у Python-аналогов.
* 🧩 **Гибридная система плагинов:**
    * **Python:** Написывайте легкие скрипты и расширения без пересборки проекта.
    * **C++ (Native C++ Plugins):** Пишите нативные `.dll` / `.so` плагины для задач, требующих максимальной скорости.
* 📦 **Легковесность:** Минимальное количество тяжелых зависимостей.
* 🛠️ **Полный функционал FunPayCardinal (в планах):** Автовыдача, автоответчик, поднятие лотов, уведомления и многое другое.

---

## 🛠️ Сборка и Требования

### Минимальные требования:
* Компилятор с поддержкой **C++20** (GCC 10+, Clang 11+, MSVC 2019+)
* **CMake** версии 3.18 или выше
* *(В будущем)* **Python 3.10+** (для поддержки Python-плагинов)

### Сборка проекта:

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/semleks/FunPaySemlex.git
cd FunPaySemlex

# 2. Создайте директорию для сборки
mkdir build && cd build

# 3. Сконфигурируйте и соберите проект
cmake ..
cmake --build .
```
